# BF6 Vector Color Picker

A tiny static color picker that displays RGB values and their normalized (RGB ÷ 255) values, plus recolorable UI icons.

## Local Preview

If you open index.html directly (file://), the icons may not load due to browser restrictions. Run a local server instead (or use GitHub Pages).

## GitHub Pages

1. Push these files to a GitHub repo.
2. In GitHub: Settings → Pages → Build and deployment → Source: Deploy from a branch.
3. Select branch `main` and folder `/root`.
4. Save and wait for the site URL.
